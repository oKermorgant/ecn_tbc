# Labs for Task-based control module @ Centrale Nantes

These labs illustrate the concept seens in [Task-based control](https://pagesperso.ls2n.fr/~kermorgant-o/teaching.html#Task-Based%20Control).

## Lab 1

Basic visual servoing with Baxter (simulated or real), on a moving sphere with a constraint on the camera horizon.

## Lab 2

Quadratic Programming approach for a Pioneer mobile robot with a pan-tilt camera.

## Lab 3

Model-predictive control for a Zoe car, on the Centrale Nantes campus.
