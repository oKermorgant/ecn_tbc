Task-based control lab at Centrale Nantes

Controlling a mobile robot with a pan-tilt camera in order to follow a trajectory and track a visual target.

## Running the simulation

Run the `simulation.sh` script in the `world` folder.

It will compile part of the project in the `build` directory, if needed.

## Doing the lab

The only file to modify should be `main.cpp`. Compile and run the `pioneer` executable to interact with the simulation.
